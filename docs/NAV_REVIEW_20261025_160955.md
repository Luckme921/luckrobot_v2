## Narrow correction

Route hysteresis previously allowed indefinite reuse when the global route remained geometrically traversable but the local controller could not execute it. The planner now stops reusing its cache after 8 seconds without at least 3 cm translation or 0.10 rad heading change, and performs the existing full search/curve validation again.

Uses steady time. Normal translation/initial rotation refresh progress. Fresh searches reset the watchdog; persistent stalls therefore receive periodic fresh search attempts. This does not guarantee a different route or successful escape, and map correction can also count as pose progress. No obstacle clearing, enlarged escape budget, speed increase, or forced motion is introduced.

Regression covers normal cache reuse, stalled cache rejection, translational progress, initial rotation, and the existing newly blocked segment check. Candidate build: five CTest suites passed. Physical blocked-start recovery remains unverified.

## Exploration review / next test

`my_robot_mapping/auto_explore.launch.py` runs the customized frontier + DFS branch-memory explorer. It scores reachable frontiers, stores sibling branches, returns through current safe routes, cools down failed regions and may reopen completed regions with new unknown-area gain. It does not blindly replay an old trajectory.

Installed exploration BT uses `LuckGrid`, `LuckFollowPath`, `explore_goal_checker`. It returns planning/tracking failure to the explorer rather than performing the manual-navigation tree's many recovery waits. Goal segments are capped at 1.20 m; same-branch continuous handoff begins within 0.45 m, subject to validation. Progress timeout 15 s; stalled-region cooldown 60 s.

The explorer submodule already has local modifications: preserve them. No exploration changes or autonomous launch in this review. First verify the corrected blocked-start/replan behavior in a supervised manual navigation recording; then test one small branched area, recording coverage, repeated branches, failed targets, handoff continuity and completion behavior before parameter changes.
