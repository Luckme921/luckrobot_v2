# V10.2 可见、限时的自动探索诊断脚本

## 修复的现象

旧脚本在真正启动 rosbag 和自动探索之前，会依次调用多个 ROS 2 参数与
生命周期服务。这些命令的输出全部写进文件，且没有超时。当 Jetson 负载高、
DDS 服务响应丢失或节点正忙时，任意调用都可能长期等待，终端看起来就像
“命令完全没反应”。

## 新行为

- 终端明确显示五个采集阶段及输出文件前缀；
- 每个启动前 ROS 2 服务检查最多等待 8 秒，失败后记录警告并继续；
- rosbag 启动失败时不会启动机器人；
- Ctrl-C 在启动前或运行中都能打包已经得到的文件；
- 结束时最多等待 rosbag 10 秒写索引，避免再次无限等待；
- 仍保持 300 秒默认记录和原有话题集合，不修改导航、控制器或碰撞参数。

## 使用

```bash
source ~/ros2_ws/install/setup.bash
bash ~/ros2_ws/tools/run_auto_diag.sh 300
```

正常情况下会立即看到 `[1/5]`。运行结束后上传脚本打印的
`~/auto_diag_*.tar.gz`。
