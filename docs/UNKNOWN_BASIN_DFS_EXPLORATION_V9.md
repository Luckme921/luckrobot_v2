# V9 UNKNOWN-basin DFS 探索设计与实车验收

## 1. V8 实车数据给出的结论

`auto_diag_20260831_160657` 记录了 182.8 秒、8 个目标、4.46 m 轮轨迹，
地图新确认约 3.02 m²。Nav2、速度链和碰撞监控均正常，问题位于探索决策：

- 日志发生 13 次回退相关事件、3 次提前关闭分支、5 次路径拒绝；
- 第一片前沿长 2.85 m、局部 UNKNOWN 收益约 2.08 m²，但机器人只走到
  0.68 m 外的白区观察点，就把前沿标记 visited 并返回父分叉；
- 0.82 m 的一个目标用了约 29.6 s，最后约 11.5 s 没有线速度，只为满足
  普通任务终点的 `0.10 rad` 航向容差；
- 成功目标到下一目标的空档为 1.2~10.1 s，DFS 误关闭分支是长空档主因，
  1 Hz 状态检查和路过点最终修姿进一步放大了停顿。

所以不能继续只调整“最近前沿/前沿长度”的权重。V9 把未知面积、宏观分支
和局部安全运动分成三层。

## 2. 三层决策

### 2.1 UNKNOWN basin：决定先探索哪条大分支

每条白/灰边界仍由 frontier search 产生，但 V9 从其所有灰色栅格同时出发，
只沿 `NO_INFORMATION` 栅格做最大 1.50 m 的有界八邻域洪泛。洪泛面积是
`unknown_gain`，质心是该分支当前的 `unknown_centroid`。

- `unknown_gain < 0.20 m²`：视为墙角、桌腿缝或地图碎洞，不生成目标；
- 根分支按路径距离、转角、前沿宽度和 UNKNOWN 面积综合排序，大未知区域
  的权重大于局部小角点；
- 同一分支不再只靠会漂移的前沿质心匹配，而以 UNKNOWN 质心距离
  `<= 1.50 m` 为主要连续性条件；
- 已完成区域后来若新增未知收益超过 `0.20 m²`，允许重新打开，避免临时
  行人或短暂扫描把房间永久删掉。

洪泛被限制在局部半径内，不会把地图外部所有灰色区域误认为一个无限大
分支；未知区只参与选择，绝不成为 Nav2 目标。

### 2.2 拓扑 DFS：决定分叉与回退

候选到机器人的已知白区路径仍用于检测公共前缀和真实分叉。未选子边连同
白区父分叉压入 LIFO 栈；当前 UNKNOWN basin 没有安全子目标后才明确返回
最近父分叉。UNKNOWN basin 匹配允许路径绕开家具发生合理弯曲，但超过约
110° 的近反转仍只能由 DFS 回退状态执行。

V8 的关键错误已删除：到达一个白区观察点不再永久 blacklist 整片前沿。
V9 只冷却当前前沿快照 1.5 s，等待 SLAM 把边界向未知区推进；相同边界若
没有推进，则冷却 20 s 并转向其他分支。

### 2.3 Nav2 局部安全连接：决定实际怎么走

运动目标仍必须同时满足：已知白区、0.20 m 车体余量、目标全局代价
`<=20`、路径前缀代价 `<=40`、单步 `<=0.85 m`。底盘驱动、RPP 速度参数、
碰撞监控和手动导航检查器都不改变。

自动探索行为树单独选择 `explore_goal_checker`：XY 容差 0.12 m，忽略路过
点最终 yaw。手动 RViz 目标仍使用 `general_goal_checker` 的 0.08 m / 0.10 rad。
这样不会为了每个局部连接点原地修姿十余秒。状态检查提高到 2 Hz、到点刷新
窗口降为 0.05 s，正常接续约为 0.05~0.55 s。本轮没有启用到点前抢占；只有
在 V9 证明分支选择稳定后，才评估滚动 `NavigateThroughPoses`。

## 3. 五分钟实车通过标准

1. 启动日志必须显示 `Unknown-basin DFS exploration V9`。
2. `V9 precheck` 必须打印 UNKNOWN gain；绝大多数选中分支应不低于
   0.20 m²，不能持续被墙角碎洞吸引。
3. 同一大分支应连续产生多个绿色目标；在 UNKNOWN 收益仍明显时，不能只走
   一步就出现 `DFS branch ... complete` 和橙色回退。
4. `V9 goal locked` 的目标仍在白区、步长 `<=0.85 m`、代价 `<=20`。
5. 局部连接点到达后不应再有数秒纯原地最终修姿；手动 RViz 目标精度不变。
6. 真正的死路、障碍或分支结束才允许回退；五分钟内 UNKNOWN 面积应持续
   减少，且单位轨迹的新确认面积明显优于 V8 的约 `0.68 m²/m`。

五分钟记录命令：

```bash
bash ~/ros2_ws/tools/run_auto_diag.sh
```

脚本默认 300 秒，结束后上传打印出的 `~/auto_diag_*.tar.gz`。
